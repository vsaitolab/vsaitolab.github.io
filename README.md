# Saito Lab website

Website of the Saito Lab (Freshwater Ecology, Environmental Sciences Department, Federal University of São Carlos – UFSCar).

Plain HTML/CSS/JS, no build step. Served with GitHub Pages.

- `index.html` – home page (research, field sites, people, publications)
- `join.html` – opportunities and photo gallery
- `pt/` – Portuguese versions of both pages (`pt/index.html`, `pt/join.html`); an EN/PT button in the menu switches languages
- `photos/` – images (`thumb/` for the gallery grid, `full/` for the lightbox, `sites/` for field-site cards)

## Editing
Edit the HTML files directly on GitHub (pencil icon) or locally, then commit. Changes go live in about a minute.

When you change text, update both the English page and its Portuguese copy in `pt/`.
